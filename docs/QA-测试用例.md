# KakaoChat Viewer — 测试用例（手工）

> 适用版本：含「系统消息解析 + 图片/视频/语音媒体」能力的 macOS Electron App  
> 运行方式：`cd kakao-chat-viewer && npm start`（**不要**用浏览器直接打开 `index.html` 测媒体）  
> 文档日期：2026-09-18

---

## 0. 测试前准备

| 项 | 要求 |
|---|---|
| 环境 | macOS，本机已安装并登录过 KakaoTalk Mac |
| 权限 | 「系统设置 → 隐私与安全性 → 完全磁盘访问」放行 **Terminal / iTerm / Cursor**（跑 `npm start` 的那个） |
| 账号 | 使用**自己的** KakaoTalk 账号数据（勿测他人机器数据） |
| 启动 | 项目目录执行 `npm start`，应进入自动模式（非手动三步） |
| 对照材料 | 准备至少：1 条文本、1 张打开过的图片、1 条语音、1 条系统消息（邀请/退群等）；可选：视频、相册、超过约 3 天的旧媒体 |

**通过标准约定**

- **P0**：阻塞发布，必须通过  
- **P1**：重要功能，应通过  
- **P2**：体验/体验/边界，尽量覆盖

## 1. 环境与启动

### TC-ENV-01 自动模式启动【P0】

| 项 | 内容 |
|---|---|
| 前置 | macOS + 完全磁盘访问已放行；本机有 KakaoTalk 数据 |
| 步骤 | 1. 执行 `npm start`<br>2. 观察启动页 |
| 预期 | 出现「正在自动读取…」步骤条（UUID → plist → userId → 数据库 → 解密），**不是**浏览器式三步手动页；成功后进入聊天列表 |
| 失败表现 | 一直停在手动模式 / 报 `tcc-blocked` / 卡死数分钟 |

### TC-ENV-02 浏览器打开无自动模式、无媒体【P1】

| 项 | 内容 |
|---|---|
| 前置 | — |
| 步骤 | 1. 用浏览器打开 `index.html` 或 `python3 serve.py` 访问<br>2. 查看界面 |
| 预期 | 只有手动配置流程；即使之后加载了库，媒体区提示「请用 npm start 打开 App」或等价说明，**不会**出现自动面板 |

### TC-ENV-03 未授权完全磁盘访问【P1】

| 项 | 内容 |
|---|---|
| 前置 | 临时取消终端的完全磁盘访问 |
| 步骤 | 1. `npm start`<br>2. 观察自动流程结果 |
| 预期 | 流程较快失败或降级，有明确权限提示；**不应**无限卡住 |
| 恢复 | 测完后重新放行权限 |

## 2. 聊天列表与文本消息

### TC-CHAT-01 聊天列表加载【P0】

| 预期 | 能看到本机聊天室；点击可进入；有消息的房间能打开对话 |

### TC-CHAT-03 加载更早消息【P1】

## 3. 系统消息 / 系统记录

### TC-SYS-01 系统 feed（邀请/退群等）【P0】

| 项 | 内容 |
|---|---|
| 前置 | 聊天室里有邀请入群、退出、被踢、改群名等系统事件（KakaoTalk 里能看到灰色系统条） |
| 步骤 | 在 Viewer 中找到对应位置 |
| 预期 | 居中灰色系统样式；文案含事件类型中文（如「邀请入群」）及人名摘要；**不是**只显示 `[系统]` 或原始 JSON |
| 备注 | 个别未知 `feedType` 可显示「系统事件(数字)」，算可接受 |

### TC-SYS-02 系统记录占位 type=1999【P1】

| 项 | 内容 |
|---|---|
| 步骤 | 浏览消息流，留意「系统记录」类条目 |
| 预期 | 可显示为系统样式，并提示占位/无正文（如已读边界）；**不要求**编造出具体业务文案 |

### TC-SYS-03 系统消息不误显示为普通气泡【P1】

| 项 | 内容 |
|---|---|
| 步骤 | 对比同一条系统事件在 KakaoTalk 与 Viewer |
| 预期 | Viewer 中为居中系统条，不是左右聊天气泡 |

## 4. 图片

### TC-IMG-01 本机已打开过的图片【P0】

| 项 | 内容 |
|---|---|
| 前置 | 在 KakaoTalk **点开过大图**的图片消息（确保本地有缓存） |
| 步骤 | 1. 在 Viewer 打开同一聊天室<br>2. 找到该图片消息 |
| 预期 | 气泡内出现可显示的图片；下方可有来源提示（如 `full` / `thumb`）；不是一直「加载中」 |
| 备注 | 若仅滚动预览过、从未点开大图，可能只有缩略图或未缓存，见 TC-IMG-02 |

### TC-IMG-02 从未点开过大图的图片【P1】

| 项 | 内容 |
|---|---|
| 前置 | KakaoTalk 里只在列表里见过、**未点开**的图片 |
| 步骤 | Viewer 中查看该条 |
| 预期 | 若 CDN 仍有效：可能出图且来源为 `cdn`；若已过期/无 URL：黄色提示「本机未缓存」或「CDN 链接已过期」等，**不崩溃** |

### TC-IMG-03 相册多图【P2】

| 项 | 内容 |
|---|---|
| 前置 | 有多图相册消息 |
| 步骤 | Viewer 中打开该条 |
| 预期 | 多帧尽量分别展示；部分有缓存、部分 CDN/失败时，失败帧单独提示，其它帧仍可显示 |

## 6. 语音 / 文件

### TC-AUD-01 未过期语音【P0】

| 项 | 内容 |
|---|---|
| 前置 | **近 3 天内**发送/收到的语音（attachment 里 CDN 通常仍有效） |
| 步骤 | Viewer 中打开该条 |
| 预期 | 出现音频播放控件，可播放；来源多为 `cdn`；提示区可有文件名 |
| 备注 | 语音一般**没有**本地缓存，完全依赖 CDN |

### TC-AUD-02 过期语音（约 3 天以上）【P0】

| 项 | 内容 |
|---|---|
| 前置 | 超过约 3 天的旧语音 |
| 步骤 | Viewer 中打开 |
| 预期 | **不能**静默空白；应提示「CDN 链接已过期」或「无本地缓存」类说明；页面其余消息正常 |

### TC-FILE-01 通用文件附件【P2】

| 项 | 内容 |
|---|---|
| 前置 | 聊天中有文件（pdf/zip 等，type 多为 18） |
| 步骤 | Viewer 中查看 |
| 预期 | CDN 有效时可下载/打开链接；过期则明确失败原因；不要求本地落盘还原 |

## 10. 已知限制（测到以下现象可记「符合设计」而非缺陷）

1. 语音/文件通常无本地文件，过期 CDN 后无法还原本体。  
2. 图片需在 KakaoTalk 打开过才有稳定本地缓存；仅列表预览可能 `not-cached`。  
3. 媒体能力仅 **Electron macOS App**；浏览器手动模式不测媒体通过。  
4. Windows 端媒体还原本链路未接，勿按 macOS 预期测 Windows 出图。  
5. `type=1999` 系统记录多为空占位，无正文属正常。  

自动化边界回归（开发自测）：`npm run test:boundary`（不替代本表手工用例）。
